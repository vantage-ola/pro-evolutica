# PES 2013 asset research

## Verified AFS containers

All 19 `.img` files in the inspected local PES 2013 `img/` directory begin with
`AFS\0`. Their little-endian entry counts and offset/size pairs pass the bounds
checks in `tools/afs_inspect.py`: 55,593 slots in total, including 1,273 empty
slots. Full per-container hashes and indices remain in ignored
`private/reports/`. These results describe this copy, not every PES 2013 edition.

The basic layout agrees with the
[cri-afs format description](https://github.com/soyjxck/cri-afs#format): four magic
bytes, a 32-bit count, then pairs of 32-bit offsets and sizes. The older
[PES6 AFS reader](https://github.com/lazanet/PES6-AFS-Tools/blob/master/AFS.java)
also reads this flat table and warns against treating Konami's extra metadata as
ordinary filenames. It does not establish PES 2013 payload compatibility.
The new reader uses the observed layout and Python's standard library; no source
code or dependencies were imported from either project.

## Smallest real sample

`dt10.img` is 26,624 bytes, with 11 slots and one empty slot.

- Archive SHA-256:
  `64e652d268d00d35b6f4b5db3ec0442b279ca1395e234a480ab6db12bd6860f4`.
- Extracted slot: index 1, offset 2,048, size 1,840 bytes.
- Extracted SHA-256:
  `227dbf38d63e78cb03e64bdef8123e73e59ec53029a3fcd7697ea3ed13bc136f`.
- Independent source read: seek to offset 2,048, read 1,840 bytes, compare with
  the extraction. Bytes and SHA-256 match.
- All ten non-empty entries begin with `00 01 01 57 45 53 59 53`, containing the
  ASCII bytes `WESYS`. Payload compression and meaning have not been validated.

The tool extracts raw entry bytes without executing, modifying or decoding them.
No sample payload or game archive is checked into Git. See
[tool usage](../TOOLS.md#inspect-an-afs-container-and-extract-one-entry).

## Remaining investigation

Verify the `WESYS` wrapper and its size fields against existing PES research and
real samples before writing a bounded decoder. Then identify one contained
texture, mesh or metadata structure and validate its interpretation. A raw AFS
entry extraction is not yet a texture or model conversion.

Executable decompilation remains pending: REA/Ghidra has not passed its health
checks, and no file-loading function addresses or engine subsystem names have
been established.
